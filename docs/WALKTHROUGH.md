## 1. 프로젝트 개요

《캣당 (CatDang)》은 '청계천 산책', '세월낚시터', '무교당', '길냥이 책방' 등 웹 브라우저에 가볍게 켜두고 일이나 공부를 하며 힐링하는 **'산사라이크(Sansa-like)' 앰비언트 메타버스 문화**를 현대적이고 세련된 고양이 3D 월드로 승화시킨 **100% 영구 무료(서버비 0원) 힐링 웹 플랫폼**입니다.

Three.js 기반의 따스한 2.5D 아이소메트릭 그래픽, 부드러운 스페이스바 점프 및 캣타워 등반 물리, Web Audio API를 활용한 실시간 무손실 음향 합성, 그리고 중앙 서버 없이 사용자 브라우저 간 직접 통신하는 WebRTC P2P 멀티플레이어를 결합하여 누구나 설치 없이 URL 클릭 한 번으로 나만의 고양이가 되어 평화로운 세계를 거닐 수 있습니다.

## 3. 핵심 시스템 아키텍처 및 상세 명세

### (1) 3D 플랫폼 높이맵 & 점프 물리 엔진 (`src/physics.js`, `src/cat.js`)
- **점프 물리**:
  - 도약 시 `jumpVelocity = 6.2` 부여, 중력 `18.0 * dt` 감속으로 약 1.07m의 쾌적한 체공 포물선 형성.
  - 착지 시 `landSquash = 0.72`로 젤리 발바닥 충격 흡수 후 점진적 형상 복원.
  - 도약 시 앞다리 전방 신전/뒷다리 굴곡 공중 모션 적용.
- **3D 플랫폼 높이 판정 (`getHeightAt(x, z, currentY)`)**:
  - 발판 간 단차를 `0.55m ~ 0.7m`로 정교하게 설계하여 고양이가 연속 점프로 한 층씩 쏙쏙 올라갈 수 있음.
  - 고양이의 현재 유효 높이(`effectiveY = currentBaseY + jumpHeight`)가 발판 높이 근처나 그 위에 도달했을 때 해당 층을 착지면으로 자동 인식.
  - 발판 가장자리로 걸어나가면 `groundY`가 아래층 또는 바닥(0m)으로 떨어지며 사뿐히 낙하 착지.
- **슬라이딩 충돌 회피 (`resolveMovement`)**:
  - 벽체나 기둥 장애물 충돌 시 X축 및 Z축 단독 미끄러짐을 계산하여 모서리에 끼이지 않는 부드러운 이동 지원.
  - 발판 상단 높이(`topY`) 이상의 고양이는 발판과의 충돌을 무시하고 발판 위를 자유롭게 활보.

### (2) 4대 정예 힐링 공간 (World Specifications)
1. **🌳 평화 공원 (`ParkWorld` - `src/worlds/park.js`)**:
   - 백옥 화이트 대리석과 황금빛 림 몰딩이 들어간 3단 대형 분수대.
   - 분수대 꼭대기의 황금 고양이 조각상(Golden Cat Statue)과 하늘 높이 솟구치는 물기둥, 8가닥 폭포수 커튼, 잔잔한 수면 동심원 파문.
   - 크림 베이지 톤의 자연스러운 곡선 오솔길과 둥근 자연석 디딤돌.
   - 아치형 목조 다리와 연못(연잎/수련꽃), 스트라이프 차양의 츄르 매점, 벤치 점프.
2. **👾 레트로 도트 마을 (`PixelWorld` - `src/worlds/pixel.js`)**:
   - 8-bit 고전 게임을 연상시키는 픽셀 잔디/흙 타일과 미니 가옥.
   - 징검다리와 도트 연못.
3. **🕊️ 하늘을 나는 고양이 (`SkyWorld` - `src/worlds/sky.js`)**:
   - 몽실몽실한 솜사탕 구름 천공섬과 파스텔 무지개 다리.
   - 천사 날개를 펄럭이며 공중을 유영하는 비행 고양이들.
   - 천공섬 외곽 낭떠러지 추락을 원천 차단하는 커스텀 바운더리 충돌체 적용.
4. **🪵 포근 다락방 찻집 (`AtticWorld` - `src/worlds/attic.js`)**:
   - 따스한 목조 마루, 깜빡이는 오렌지 불빛의 벽난로, 도자기 찻잔과 냥이 물그릇이 놓인 찻상.
   - **4대 캣타워 라인업**:
     - *초대형 4단 루프탑 캣 콘도*: 1단 웰컴 데크(0.55m) ➔ 2단 통나무 숨숨집(1.25m) ➔ 3단 핑크 캣 해먹 & 쥐돌이 방울 모빌(1.95m) ➔ 4단 최상층 구름 조망대(2.75m).
     - *나선형 스텝 타워*: 굵은 통나무 기둥 주위로 45도씩 회전하는 4단 나선 계단과 꼭대기 원형 라운지(2.75m).
     - *벽면 캣워크 & 벽난로 공중 브릿지*: 1단 스크래쳐 ➔ 2단 벽면 선반 ➔ 3단 공중 현수교 ➔ 벽난로 위 굴뚝 쉼터(2.6m).
     - *테라스 미니 바스켓*: 썬베드 옆 낮잠용 2단 바스켓 타워(1.2m).
   - 시야를 가리던 오른쪽(동쪽) 벽을 없애고 뭉게구름 하늘 배경이 탁 트인 디오라마 오픈 뷰 구축.

### (3) Web Audio 실시간 무손실 사운드스케이프 (`src/audio.js`)
- **점프 효과음 (`playJump`)**: Bandpass 필터를 통과한 경쾌한 주파수 핑(`240Hz ➔ 620Hz`)으로 도약감 연출.
- **착지 효과음 (`playLand`)**: 푹신한 젤리 발바닥 착지를 연상시키는 저음 퍽(`140Hz ➔ 45Hz`) 감쇠.
- **골골송 (Purring Engine)**: `28Hz` 초저주파 오실레이터를 진폭 변조(AM)하여 실제 고양이가 몸을 울리는 골골송 재현 (식빵 굽기 시 볼륨 2.5배 증폭).
- **묘당 풍경(風鈴)**: 5음계 펜타토닉(Eb6, F6, Ab6, Bb6, C7) 금속 차임벨 공명 합성.

### (4) 서버비 0원 WebRTC P2P 네트워크 (`src/network.js`)
- 중앙 게임 서버를 일체 두지 않고, PeerJS 브로커를 통해 클라이언트 간 DataChannel 직접 메시지 교환.
- 패킷 구조 최적화: 위치(`x, y, z`), 회전 각도, 애니메이션 상태(`walk, idle, loaf, stretch, jump`), 실시간 말풍선 텍스트 전송.
- 유저 부재 시에도 공원이 적막하지 않도록 자율 냥이 4마리가 상시 거닐며 생태계 유지.

## 4. 인프라 및 배포 파이프라인

- **Vite 번들 최적화 (`vite.config.js`)**:
  - `base: './'` 설정으로 GitHub Pages 하위 경로(`/catdang/`) 및 루트 배포 모두 완벽 호환.
  - Three.js, PeerJS 청크를 분리하여 초기 로딩 번들 크기 경량화 (빌드 타임: **~800ms**).
- **GitHub Actions CI/CD (`.github/workflows/deploy.yml`)**:
  - `main` 브랜치 푸시 시 자동 빌드 후 GitHub Pages 환경으로 배포 (배포 완료 시간: **20초**).
  - Vercel 배포 호환을 위한 `vercel.json` 번들링.

## 6. 결론

본 프로젝트는 불필요하게 파편화되었던 요소들을 걷어내고 가장 핵심이 되는 **평화 공원**과 **포근 다락방 찻집**의 디테일(분수대, 오솔길, 4대 캣타워 3D 등반 시스템)을 완벽한 수준으로 마감했습니다. 

단 하나의 루트 커밋으로 정돈된 저장소와 20초 만에 전 세계로 배포되는 CI/CD 파이프라인을 바탕으로, 누구나 영구히 0원의 비용으로 접속하여 즐길 수 있는 고품질 힐링 웹 메타버스가 성공적으로 완성되었습니다.
